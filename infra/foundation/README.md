# infra/foundation — slipway platform `slipway` (dev)

Generated by `platform.cjs` from `platform.yaml`. Owns the organisation's registry `acrslipwaydev`, key vault `kv-slipway-dev`, Container Apps environment `cae-slipway-dev`, Log Analytics `log-slipway-dev`, the optional shared apps identity `id-slipway-apps-dev`. The resource group, the state storage and the CI/CD identity `id-slipway-cicd-dev` come from `setup-platform.sh`.

| Step | Who | Command |
|---|---|---|
| Plan | anyone with Reader on the subscription | `export ARM_SUBSCRIPTION_ID=$(az account show --query id -o tsv); terraform -chdir=infra/foundation init && terraform -chdir=infra/foundation plan -out=tfplan.dev` |
| Apply | the platform owner, after reading the plan | `terraform -chdir=infra/foundation apply tfplan.dev` |
| Conditioned grants for per-app identities (after the apply) | a subscription **Owner** | `bash setup-platform.sh --grant-per-app-roles` |

State: `stslipwaytf/tfstate/slipway/platform/dev.tfstate` (Entra ID auth). Never `-auto-approve`, never `destroy`: repositories of the whole organisation depend on these resources.
